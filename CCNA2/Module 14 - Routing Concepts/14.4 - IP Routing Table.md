## ___Route Sources___
- A routing table contains: __List of routes to known networks__(Prefix and prefix length)
- Information gains from:
	- __Directly connected networks__
	- __Statics routers__
	- __Dynamic routing protocols__
___
## ___Routing Table Principles___

| Routing Table Principle                                                                                | Example                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every router make its decision alone, based on the information it has in its own routing table         | __R1__ can only forward packets using its own table<br>__R1__ doesn't know what routes are in the tables of other routers.                                                                                                                                                  |
| The information in a table of one router doesn't necessarily match the routing table of another router | Just because R1 has a route in its table to a network via __R2__, doesn't mean that __R2__ knows about the same network.                                                                                                                                                    |
| Routing information about a path doesn't provide return routing info.                                  | R1 receive a packet with the destination IP of __PC1__ and the source IP of __PC3__. Just because R1 knows to forward the packet out to __G/0/0/0__, doesn't mean that that it knows how to forward packets originating from __PC1__ back to the remote network of __PC3__. |

## ___Directly Connected Network___
- Router must have at least one active interface configured with an IP address + subnet mask before it can learn about any remote network.
- Denoted by status code of __C__ in the table.
- Local route for each its directly connected networks, denoted by code __L__.
___
## ___Static Routes___
- Manually configured.
- Not auto updated.
- Improved security and recourses efficiency.
- Use less bandwidth than __dynamic routing protocols__.
___
___Primary uses:___
- Provide ease of routing table maintenance in smaller networks.
- It uses a single default route to represent a path to any network that doesn't have a more specific match with other route in table.
- It routes __to__ and __from__ stub networks. Networks accessed by a single route. The router has only one neighbor.
___
## ___Dynamic Routing Protocols___
- Used to automatically share information.
- Advantages are the ability to select a best path, and the ability to auto discover a new best path when there is a change in topology.
___
## ___Default Route___
- Similar to a default gateway.
- Specifies the next-hop router to use when routing table doesn't contain a specific route.
- __Default route:__ 0.0.0.0/0, or ::0 in IPv6
___
## ___Structure of an IPv4 Routing Table___
- Based on how the routing process searches the IPv4 the table for the longest match, the addresses are __left justified__ or __indented__.
- __Indented entry__ - child route (subnet, directly, classful address) 
___
## ___Administrative Distance___
- Only one dynamic routing protocol should be on the router, but it is possible to configure both __OSPF and EIGRP__.
- __Administrative Distance (AD)__ - Represents "trustworthiness" of the route. The lower AD, the trustworthy the router source.
