## ___Decision Process___
![[Screenshot 2026-05-12 185247.png]]
- ___Device on a Directly Connected Network___
	- Packet can be forwarded directly to the destination device
	- Packet must be encapsulated in a Frame. Based on whether it is IPv4 or IPv6
	- __IPv4__ - Router check ARP table, for the destination address and an MAC address. If not match, sends ARP request 
	- __IPv6__ - Router checks his neighbor cache. If not match, sends ICMPv6 NS message.
- ___Forward the packet to a next-hop Router___
	- If the route entry indicates that the destination IP address is on a __remote network__, the packet must be forwarded to a __next-hop__ router.
	- The next-hop address is indicated in the router entry.
