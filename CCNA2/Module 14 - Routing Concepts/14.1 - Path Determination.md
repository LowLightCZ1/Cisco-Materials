- __Switch__ - Connect more ethernet devices into one network
- __Router__ - Connect multiple networks 
- Router using __routing table__ to determine witch path (route) to use for current packet.
___
## ___Best Path Equals Longest Match___
- __The longest match__ - Process the router uses to find a match between the __destination IP__ and a __routing entry__.
___Routing table:___
	- prefix (network address)
	- prefix length
- A minimum number of __farl-left__ bits must match between IP and the route for there to be a match.
- Longest match - that has greatest number of far-left matching bits
