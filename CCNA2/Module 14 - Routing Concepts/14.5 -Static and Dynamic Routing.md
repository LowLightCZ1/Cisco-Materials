## ___Static or Dynamic ?___
- __Static Route__
	- As a default route forwarding packets to a service provider.
	- For routers outside the routing domain and not learned by the dynamic routing protocol.
	- When the network administrator wants to explicitly define the path of a specific network.
	- For routing between stub networks
- __Dynamic Route___
	- In network consisting of more than just few routers.
	- When a change in the network topology requires the network to automatically determine another path.
	- For scalability. As the network grows, the dynamic protocol automatically learns about any new network.
___
## ___Dynamic Protocol Concepts___
- __Purpose:__
	- Discovery of remote network.
	- Maintaining up-to-date routing information.
	- Choosing the best path to destination network.
	- Ability to find a new best path if the current path is no longer available.
- __Main Components__
	- __Data Structure__ - Protocols usually use database or tables kept in RAM.
	- __Routing protocol messages__ - Used for discover neighbors, exchange routing information, etc. 
	- __Algorithm__ - Finite list of steps used to accomplish task. 
___
## ___Best Path___
- Determining the path may involve the __evaluation__ of multiple paths to the same destination network.
- Selected by a routing protocol.

| Routing Protocol                                       | Metric                                                                                                                                                             |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Routing Information Protocol**                       | - The metric is "hop count"<br>- Each router along a path adds a hop to a hop count<br>- A max of 15 hops allowed                                                  |
| **Open Shortest Path First (OSPF)**                    | - The metric is  "cost" which is based on the cumulative bandwidth from source to destination.<br>- Faster links are assigned lower costs compared to slower links |
| **Enhanced Interior Gateway Routing Protocol (EIGRP)** | - It calculate a metric based on the slowest bandwidth and delay values<br>- It could also include load an reliability into a metric calculation.                  |
___
## ___Load Balancing___
- When router has two or more paths to a destination with equal cost metric, it forwards the packets using both paths equally.
- Automatically implemented by dynamic routing protocols.
> Note: Only __EIGRP__ support unequal cost load balancing.
