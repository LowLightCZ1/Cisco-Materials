## ___Types of Static Routes___
- __Standard static route__
- __Default static route__
- __Floating static route__
- __Summary static route__
___
## ___Next-hop Options___
- __Next-hop route__ - Only the next-hop IP address is specified.
- __Directly connected static route__ - Only the router exit interface is specified.
- __Full specified static route__ - The next-hop IP and exit interface are specified.
___
## ___IPv4 Static Route Command___
__IPv4__ - ``R1(config) ip route "network-address" "subnet-mask" {"ip-address" | "exit-intf"}``
__IPv6__ - ``R1(config) ipv6 route "ipv6-prefix/prefix-length"  {"ipv6-address" | "exit-intf"}``
