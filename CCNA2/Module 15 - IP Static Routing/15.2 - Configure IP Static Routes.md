## ___Next-hop static route___
- Only next-hop address is specified.
- The exit interface is derived from the next-hop.
__Example:__![[Screenshot 2026-05-26 190645.png]]
Remote networks
 ```
 R1(config)# ip route 172.16.1.0 255.255.255.0 172.16.2.2
 R1(config)# ip route 192.168.1.0 255.255.255.0 172.16.2.2
 R1(config)# ip route 192.168.2.0 255.255.255.0 172.16.2.2
 ```
 ___
## ___Directly Connected Static Route___
- Use the exit interface to specify the next-hop address
```
R1(config)# ip route 172.16.1.0 255.255.255.0 s0/1/0
R1(config)# ip route 192.168.1.0 255.255.255.0 s0/1/0
R1(config)# ip route 192.168.2.0 255.255.255.0 s0/1/0
```
___
## ___Full Specified Static Route___
- Both exit interface and next-hop address are specified.
- Used when the exit interface is __multi-access interface__.
- __Difference:__
	- __Point-to-point serial network__ - Has only one other device on a network, the router on the another end.
	- __Multi-access interface network__ - May be many different devices sharing the same multi-access network.
```
R1(config)# ip route 172.16.1.0 255.255.255.0 GigabitEthernet 0/0/1 172.16.2.2
R1(config)# ip route 192.168.1.0 255.255.255.0 GigabitEthernet 0/0/1 172.16.2.2
R1(config)# ip route 192.168.2.0 255.255.255.0 GigabitEthernet 0/0/1 172.16.2.2
```
