- __Host route__ - IPv4 address with 32-bit mask, or IPv6 address with 128-bit mask
- __Ways to add host route__
	- Automatically installed when an IP is configured on the router.
	- Configure as a static host route.
	- Host route automatically obtained trought other methods.
___

## ___Automatically Installed Host Route___
- Cisco ISO Automatically installs a host route, also known as a __local host route__.
___
## ___Static Host Routes___
- Uses a destination IP address and a __255.255.255.255 (/32)__ mask.
- Can be manually configured to direct traffic to a specific destination device.
