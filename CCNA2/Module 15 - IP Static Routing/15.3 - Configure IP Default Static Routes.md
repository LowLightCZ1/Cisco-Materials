- Static route that matches all packets.
- Used when no other routes in table match the destination IP of the packet. (Used as Gateway of Last Resort)
- Used when connecting an edge router to a service provider network, or a __stub router__ (router with only one upstream neighbor router)
- __Default Static Route___
	- Command syntax for any other IP static route
	- Network address + mask - __0.0.0.0 0.0.0.0__
