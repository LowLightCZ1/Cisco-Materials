- Used to provide a backup path to a primary __static or dynamic__ router.
- Only used when primary router is unable.
___
- Router is configured with a __higher administrative distance__ (trustworthiness).
- If multiple paths exists, the router will choose the path with the lowest administrative distance.
___
- __Static administrative distance__ - 1
- __EIGRP__ - 90
- __OSPF__ - 110
- __IS-IS__ - 115
