## ___[[10.2 - Access Control| SNMP and RADIUS ]]___
- Topology:  ![[Screenshot 2026-04-27 184122 1.png]]
- PC-A running __SNMP (Simple Network Management Protocol)__ and __RADIUS__ server software.
- __SNMP__ - Used to monitor the network. SNMP log messages == _traps_.
- __RADIUS__ - Used for AAA. Instead of entering a pre-shared key, users enter their own __username and password__ credentials.
___
## ___Configure the SNMP (Cisco version)___
- click __MANAGEMENT__ tab.
- Click __SNMP__
- Click __Trap Receivers__
- Click __New...__
- Enter the SNMP Community name and the IP.
___
## ___Configure the RADIUS server (Cisco version)___
- Click __SECURITY__
- Click __RADIUS__
- Click __Authentication__
- Click __New...__
- Enter IPv4 address and the __shared secret__.
___
## ___Topology with VLAN 5 Addressing___
- Each WLC has 5 physical ports.
- Each WLAN on WLC needs its own __virtual interface__.
- Port - can support more WLANs
___
## ___Configure the new Interface___
- Create a new interface (__CONTROLLER__ section)
- Config the VLAN name and ID.
- Config the port and interface address
- Configure the DHCP server address
- Apply and confirm
- Verify interface.
