## ___Network Change___
- There are some events that can cause changes.
	- Interface can fail,
	- Service provider can drops a connection,
- Administrators must be familiar with tools to help isolate problem and solve it.
___
## ___Common Troubleshooting Commands___
- __ping__
- __traceroute__
- **show ip  route**
- **show ip interface brief**
- **show cdp neighbors detail**
___
